## Before / After

### Before (bug)

`buildTurnProjection` in `Finalize/State.hs` read external-query telemetry from `tiExternalQueryResult ti` (TurnInput).  This field was initialized to `Nothing` in `Prepare/Build.hs` and never populated by the render phase.  Result:

- `trcLearningQueryType` → `Nothing` (always)
- `trcExternalTool` → `Nothing` (always)
- `trcLearningValidationStatus` → `Just "not_attempted"` (always)
- `trcLearningRejectReason` → `Nothing` (always)

The telemetry was **blind**: even when an external query was executed, rendered, and its result stored in `taExternalQueryResult`, the replay trace showed "not_attempted".

### After (fixed)

`buildTurnProjection` now reads from `taExternalQueryResult ta` (TurnArtifacts), the field populated by `resolveRenderEffects` → `buildTurnArtifacts` → `rerExternalQueryResult`.

Result when external query executes:
- `trcLearningQueryType` → `Just "external"`
- `trcExternalTool` → `Just <toolName>`
- `trcLearningValidationStatus` → `Just "transport_error"` / `Just "pending_validation"`
- `trcLearningRejectReason` → `Just <rendered error>` (on failure)

Result when no external query attempted:
- All fields remain `Nothing` / `Just "not_attempted"` as before.

---

## Root Cause

The render-phase wiring (`Route/Render.hs`) correctly stored the external query result in `taExternalQueryResult`, but the finalize-phase telemetry builder (`Finalize/State.hs`) read from a parallel field on `TurnInput` (`tiExternalQueryResult`) that was never updated.  The two fields drifted: one had data, the other was always `Nothing`.

## Fix Details

### WP1 — Telemetry source fix (`c9d9027`)

File: `src/QxFx0/Core/TurnPipeline/Finalize/State.hs`

Replaced 4 occurrences of `tiExternalQueryResult ti` with `taExternalQueryResult ta` in `buildTurnProjection`:
- `trcLearningQueryType`
- `trcExternalTool`
- `trcLearningValidationStatus`
- `trcLearningRejectReason`

### WP2 — Dead code cleanup (`c62eb95`)

Files:
- `src/QxFx0/Core/TurnPipeline/Types.hs` — removed `tiExternalQueryResult` field from `TurnInput`
- `src/QxFx0/Core/TurnPipeline/Prepare/Build.hs` — removed `tiExternalQueryResult = Nothing` initialization

This eliminates the possibility of future drift: there is now **one** source of truth for the external query result — `taExternalQueryResult` in `TurnArtifacts`.
