    7 {-|
    8 Module      : QxFx0.Self.Deliberation
    9 Description : Phase-8 deliberation framework — symbiotic reconciliation
   10               of two hemispheric proposals into one outgoing 'Plan'.
   11 
   12 == What this module is
   13 
   14 A pure, leaf-level realisation of the deliberation contract pinned
   15 by ADR-0011 (forthcoming). It introduces a single composite
   16 'Plan' record that carries every output decision the dual-mode
   17 runtime currently makes (family / render-style / recovery cause /
   18 narrative tone) plus a self-reported confidence, and a single
   19 morphism
   20 
   21 @
   22 'reconcile' :: 'Salience' -> 'HolisticProposal' -> 'FormalProposal' -> 'Field' -> 'Deliberation'
   23 @
   24 
   25 that takes one proposal from each hemisphere (a 'Holistic' 'Plan'
   26 on the right, a @'Field' -> 'Plan'@ strategy on the left, both
   27 typed through the existing 'QxFx0.Self.Adjunction.Adjunction'
   28 spine) and produces a reconciled 'Plan' together with a structured
   29 'DeliberationTrace' that records /both/ proposals and the
   30 reconciliation rule that was applied.
   31 
   32 This replaces the previous \"priority switching\" pattern (where
   33 the salience verdict picked one of two values to forward) with a
   34 \"deliberation\" pattern (where both values are always materialised
   35 and a typed reconciliation chooses the outgoing payload field by
   36 field). The single-output discipline of ADR-0010 §5 is preserved:
   37 the caller forwards exactly one 'Plan'; the trace carries both.
   38 
   39 == What this module is /not/
   40 
   41 This module is the algebraic /shape/ of deliberation. It does not
   42 import from @QxFx0.Core.*@ and does not know anything about turn
   43 pipelines, routing cascades, render strategies, or recovery sites.
   44 The Phase-8 milestones (B.5.M1 / M2 / M3) are responsible for
   45 constructing 'HolisticProposal' / 'FormalProposal' values from the
   46 existing routing inputs and consuming the reconciled 'Plan' at the
   47 three call sites currently using salience-based priority switching.
   48 
   49 == Decision rule (overview)
   50 
   51 Six rules apply in priority order; the first that matches becomes
   52 'dtRule' on the returned trace:
   53 
   54 1.  'RuleConatusOverride' — if @'salienceDriver' = 'DrivenByConatusGate'@
   55     the formal proposal is forced into a recovery shape regardless
   56     of the holistic proposal.
   57 2.  'RuleAgreement' — if both proposals match field-for-field
   58     (modulo 'planConfidence'), the merged confidence is the max
   59     of the two.
   60 3.  'RuleSalienceLead' — if 'salienceConfidence' exceeds
   61     'smEscalationConfidenceFloor', the verdict-side proposal wins
   62     wholesale.
   63 4.  'RuleHolisticAdvantage' / 'RuleFormalAdvantage' — when exactly
   64     one of (family, style, tone) differs, the verdict side decides
   65     that single axis.
   66 5.  'RuleTiedFallback' — formal proposal wins as the safe default
   67     (matches ADR-0010 §5).
   68 
   69 In every non-Conatus rule, 'planRecoveryCause' is determined by
   70 'pickHigherSeverity' across both proposals — recovery is never
   71 silenced by a high-bias holistic proposal.
   72 
   73 == Honest scope
   74 
   75 The default 'NarrativeNeutral' tone, the 'recoveryCauseSeverity'
   76 ordering, and the per-axis differs/equal classification are pinned
   77 to make the property tests pass and the operational mapping
   78 (ADR-0011) plausible. Calibration of the severity ladder against
   79 empirical recovery preferences is Phase-7 (lifeness gates) work.
   80 -}

  163 
  164 -- | A composite proposal from one hemisphere for a single turn.
  165 --
  166 -- Aggregates every output decision currently scattered across
  167 -- routing, render-style, and recovery so that two proposals can
  168 -- be compared field-for-field by 'reconcile'.
  169 --
  170 -- Invariants:
  171 --
  172 --   * @0 \\<= 'planConfidence' \\<= 1@.
  173 --   * 'planRecoveryCause' = 'Just' /c/ implies the proposing
  174 --     hemisphere asserts a recovery condition; 'Nothing' means it
  175 --     does not. Whether the merged plan emits recovery is decided
  176 --     by 'pickHigherSeverity' across both sides, not by either
  177 --     side alone.

  184     -- ^ A proposed recovery cause, or 'Nothing' to abstain.
  185     --   Recovery is never silenced by 'reconcile' — see
  186     --   'pickHigherSeverity' / 'RuleConatusOverride'.
  187   , planNarrativeTone :: !NarrativeTone
  188     -- ^ The proposed narrative tone.
  189   , planConfidence    :: !Double
  190     -- ^ How confident the proposing hemisphere is in this 'Plan',
  191     --   in @[0, 1]@.
  192   }
  193   deriving stock (Eq, Show)

  341 -- ---------------------------------------------------------------------------
  342 -- Recovery severity ladder
  343 -- ---------------------------------------------------------------------------
  344 
  345 -- | Total order on 'LocalRecoveryCause' used to merge two
  346 -- proposals\' 'planRecoveryCause' fields.
  347 --
  348 -- 'Nothing' is the floor (severity @0@); a structural-Conatus
  349 -- event is the ceiling. This ordering is the single source of
  350 -- truth for B.3.5 (\"recovery is never silenced\"): the proposal
  351 -- with higher severity wins on the recovery axis regardless of
  352 -- the salience verdict.
  353 --
  354 -- Numbers are deliberately spaced so future variants slot in
  355 -- without renumbering the existing ladder.
  356 recoveryCauseSeverity :: Maybe LocalRecoveryCause -> Int
  357 recoveryCauseSeverity Nothing                          = 0
  358 recoveryCauseSeverity (Just RecoveryParserLowConfidence) = 20
  359 recoveryCauseSeverity (Just RecoveryLowLegitimacy)       = 30
  360 recoveryCauseSeverity (Just RecoveryUnknownTopic)        = 40
  361 recoveryCauseSeverity (Just RecoveryShadowUnavailable)   = 50
  362 recoveryCauseSeverity (Just RecoveryShadowDivergence)    = 60
  363 recoveryCauseSeverity (Just RecoveryRuntimeDegraded)     = 70
  364 recoveryCauseSeverity (Just RecoveryRenderBlocked)       = 80
  365 recoveryCauseSeverity (Just RecoveryLearningNeed)        = 85
  366 recoveryCauseSeverity (Just RecoveryConatusGate)         = 100
  367 
  368 -- | Pick the higher-severity recovery proposal per
  369 -- 'recoveryCauseSeverity'. Ties favour the left argument so the
  370 -- function is stable under repeated calls.
  371 pickHigherSeverity
  372   :: Maybe LocalRecoveryCause
  373   -> Maybe LocalRecoveryCause
  374   -> Maybe LocalRecoveryCause
  375 pickHigherSeverity a b
  376   | recoveryCauseSeverity a >= recoveryCauseSeverity b = a
  377   | otherwise = b

  401 -- ---------------------------------------------------------------------------
  402 -- The deliberation morphism
  403 -- ---------------------------------------------------------------------------
  404 
  405 -- | Reconcile a holistic and a formal proposal under a salience
  406 -- verdict, producing a 'Deliberation' record that includes both
  407 -- projected proposals, the reconciled 'Plan', and a per-turn
  408 -- 'DeliberationTrace'.
  409 --
  410 -- Total, deterministic, pure. Identical inputs produce identical
  411 -- 'Deliberation' values, including 'dtRule' and 'dtAgreement'.
  412 --
  413 -- Rule priority (first match wins; see module-level overview for
  414 -- the rationale):
  415 --
  416 --   1.  'RuleConatusOverride' on @'salienceDriver' = 'DrivenByConatusGate'@.
  417 --   2.  'RuleAgreement' on field-for-field equality (modulo
  418 --       'planConfidence').
  419 --   3.  'RuleSalienceLead' when @'salienceConfidence' >
  420 --       'smEscalationConfidenceFloor' 'defaultSalienceModulation'@.
  421 --   4.  'RuleHolisticAdvantage' / 'RuleFormalAdvantage' on
  422 --       single-axis disagreement (excluding the recovery axis).
  423 --   5.  'RuleTiedFallback' otherwise — formal proposal wins as
  424 --       the safe default (ADR-0010 §5).
  425 --
  426 -- The recovery axis is always merged via 'pickHigherSeverity',
  427 -- regardless of which rule fires (except 'RuleConatusOverride',
  428 -- which forces 'Just' 'RecoveryConatusGate' wholesale).
  429 reconcile
  430   :: Maybe (Plan -> Bool)   -- ^ Phase 10: optional courtesy predicate.
  431                               -- When 'RuleTiedFallback' fires and this is
  432                               -- 'Just p', the tie-break prefers the
  433                               -- proposal that satisfies @p@, but only
  434                               -- if exactly one does.  Never widens the
  435                               -- admissible set.
  436   -> Salience
  437   -> HolisticProposal
  438   -> FormalProposal
  439   -> Field
  440   -> Deliberation
  441 reconcile mCourtesy salience hp fp fd =
  442   let hPlan          = groundIn hp
  443       fPlan          = probe fp fd
  444       driver         = salienceDriver salience
  445       agreement      = classifyAgreement hPlan fPlan
  446       divergence     = computeDivergence hPlan fPlan
  447       mergedRecovery = pickHigherSeverity (planRecoveryCause hPlan) (planRecoveryCause fPlan)
  448       mkTrace rule = DeliberationTrace
  449         { dtAgreement      = agreement
  450         , dtDivergence     = divergence
  451         , dtRule           = rule
  452         , dtSalienceDriver = driver
  453         }
  454       mkResult plan rule = Deliberation
  455         { delibHolistic   = hPlan
  456         , delibFormal     = fPlan
  457         , delibReconciled = plan
  458         , delibTrace      = mkTrace rule
  459         }
  460    in case driver of
  461         DrivenByConatusGate ->
  462           let conatusPlan = fPlan
  463                 { planRenderStyle   = StyleRecovery
  464                 , planRecoveryCause = Just RecoveryConatusGate
  465                 , planNarrativeTone = NarrativeRecovery
  466                 , planConfidence    = 1.0
  467                 }
  468            in mkResult conatusPlan RuleConatusOverride
  469 
  470         _ | plansEqualModConfidence hPlan fPlan ->
  471               let agreedPlan = hPlan
  472                     { planConfidence    = max (planConfidence hPlan) (planConfidence fPlan)
  473                     , planRecoveryCause = mergedRecovery
  474                     }
  475                in mkResult agreedPlan RuleAgreement
  476 
  477         _ | salienceConfidence salience > smEscalationConfidenceFloor defaultSalienceModulation ->
  478               let chosen = case salienceVerdict defaultSalienceWeights salience of
  479                     PreferHolistic _ -> hPlan
  480                     PreferFormal   _ -> fPlan
  481                     Tied             -> fPlan
  482                   withRecovery = chosen { planRecoveryCause = mergedRecovery }
  483                in mkResult withRecovery RuleSalienceLead
  484 
  485         _ | singleNonRecoveryAxisDiffers hPlan fPlan ->
  486               let (rule, base) = case salienceVerdict defaultSalienceWeights salience of
  487                     PreferHolistic _ -> (RuleHolisticAdvantage, hPlan)
  488                     PreferFormal   _ -> (RuleFormalAdvantage,   fPlan)
  489                     Tied             -> (RuleFormalAdvantage,   fPlan)
  490                   withRecovery = base { planRecoveryCause = mergedRecovery }
  491                in mkResult withRecovery rule
  492 
  493         _ ->
  494               let baseFallback = fPlan { planRecoveryCause = mergedRecovery }
  495                   fallback = case mCourtesy of
  496                     Nothing -> baseFallback
  497                     Just pred ->
  498                       case (pred hPlan, pred fPlan) of
  499                         (True, False) -> hPlan { planRecoveryCause = mergedRecovery }
  500                         _             -> baseFallback
  501                in mkResult fallback RuleTiedFallback

  541 -- | Field-for-field equality on 'Plan' that ignores
  542 -- 'planConfidence'. Used by 'RuleAgreement'.
  543 plansEqualModConfidence :: Plan -> Plan -> Bool
  544 plansEqualModConfidence a b =
  545      planFamily        a == planFamily        b
  546   && planRenderStyle   a == planRenderStyle   b
  547   && planRecoveryCause a == planRecoveryCause b
  548   && planNarrativeTone a == planNarrativeTone b
  549 
  550 -- | Classify how the two plans differ across the four axes.
  551 classifyAgreement :: Plan -> Plan -> Agreement
  552 classifyAgreement a b =
  553   let famDiff = planFamily        a /= planFamily        b
  554       styDiff = planRenderStyle   a /= planRenderStyle   b
  555       recDiff = planRecoveryCause a /= planRecoveryCause b
  556       tonDiff = planNarrativeTone a /= planNarrativeTone b
  557       diffs   = [famDiff, styDiff, recDiff, tonDiff]
  558       n       = length (filter id diffs)
  559    in case n of
  560         0 -> Agree
  561         1
  562           | famDiff -> DivergeOnFamily
  563           | styDiff -> DivergeOnStyle
  564           | recDiff -> DivergeOnRecovery
  565           | tonDiff -> DivergeOnTone
  566           | otherwise -> Agree
  567         _ -> DivergeMultiple
  568 
  569 -- | Number of differing axes / 4. Always in @[0, 1]@.
  570 computeDivergence :: Plan -> Plan -> Double
  571 computeDivergence a b =
  572   let count = length . filter id $
  573         [ planFamily        a /= planFamily        b
  574         , planRenderStyle   a /= planRenderStyle   b
  575         , planRecoveryCause a /= planRecoveryCause b
  576         , planNarrativeTone a /= planNarrativeTone b
  577         ]
  578    in fromIntegral count / 4.0
  579 
  580 -- | Predicate: do the two plans differ on exactly one of
  581 -- @{family, style, tone}@? The recovery axis is excluded because
  582 -- it is always merged separately via 'pickHigherSeverity'.
  583 singleNonRecoveryAxisDiffers :: Plan -> Plan -> Bool
  584 singleNonRecoveryAxisDiffers a b =
  585   let diffs =
