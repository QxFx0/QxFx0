    8 Module      : QxFx0.Self.Conatus
    9 Description : Phase-2 Conatus functional over the SelfBlanket.
   10 
   11 A typed, pure realisation of the scalar functional named in
   12 @docs\/THEORY.md@ §4.2 and elaborated in @docs\/adr\/0007-dual-mode-conatus.md@.
   13 
   14 == Theoretical Sketch
   15 
   16 Following the Spinozan reading committed in @docs\/THEORY.md@, every
   17 finite mode persists by an inner endeavour — a /conatus/. We do not
   18 claim the present implementation possesses anything like the conatus
   19 of a living substance; we claim only that the system's structural
   20 self-identity can be summarised by a scalar functional whose
   21 behaviour mirrors the formal /shape/ of conatus:
   22 
   23 * It is positive when the system is intact as /this system/.
   24 * It decreases — strictly, by a fixed step — for each
   25   structural invariant the system has violated.
   26 * It admits a gradient pointing in the direction of fastest increase,
   27   which serves as a /direction of recovery/ in Phase 2.5.
   28 
   29 Concretely, we project a 'QxFx0.Self.Types.SelfBlanket' \(b = (m, c, t)\)
   30 together with a list of 'QxFx0.Self.Types.BlanketViolation's \(v\) to:
   31 
   32 \[
   33 C(b, v) = w_m \cdot \log(1 + m) + w_c \cdot \log(1 + c) + w_t \cdot \log(1 + t) - \lambda \cdot |v|
   34 \]
   35 
   36 where \(m, c, t\) are the morphology size, identity-claim count, and
   37 turn count from the blanket, and \(w_m, w_c, w_t, \lambda\) are
   38 tunable coefficients ('ConatusWeights'). The logarithmic shape
   39 captures /diminishing returns/: a system gains a great deal of
   40 identity by acquiring its first hundred morphological entries and
   41 proportionally less by acquiring its next hundred. The penalty term
   42 is discrete; violations contribute only to the scalar, not to the
   43 gradient.
   44 
   45 The gradient
   46 
   47 \[
   48 \nabla C(b) = \left( \frac{w_m}{1 + m}, \frac{w_c}{1 + c}, \frac{w_t}{1 + t} \right)
   49 \]
   50 
   51 is computed analytically (no automatic-differentiation dependency).
   52 Each component is strictly positive on non-degenerate blankets and
   53 /decreases/ as its axis grows — operationally: when several axes
   54 have degraded, recovery should preferentially restore the one whose
   55 current value is smallest, because the marginal gain in Conatus is
   56 largest there.
   57 
   58 == Scope and Honesty
   59 
   60 This module is /not/ a model of subjective drive, motivation, or
   61 phenomenal striving. It is a structural functional over a tiny
   62 finite-dimensional summary of the system state, designed so that
   63 later phases (recovery, salience control, dual-mode arbitration)
   64 have a single principled scalar/gradient to consult instead of
   65 hand-coded heuristics. See @docs\/THEORY.md@ §5 for the explicit
   66 list of what we do /not/ claim.
   67 -}

   93 -- | Tunable coefficients of the Conatus functional. The defaults
   94 -- in 'defaultConatusWeights' encode the editorial judgement that
   95 -- morphological substance is the primary carrier of identity
   96 -- (largest weight), accumulated identity claims are secondary, and
   97 -- raw turn count is a weaker indicator (a long-running session of
   98 -- empty turns says less than a short session with rich growth).
   99 -- The violation penalty is intentionally large relative to any
  100 -- single-axis logarithmic contribution: a structural rupture must
  101 -- not be wallpapered over by mere accumulation.
  102 data ConatusWeights = ConatusWeights
  103   { cwMorphology :: !Double
  104     -- ^ Weight on \(\log(1 + m)\). Default: @1.0@.
  105   , cwIdentity   :: !Double
  106     -- ^ Weight on \(\log(1 + c)\). Default: @0.5@.
  107   , cwTurns      :: !Double
  108     -- ^ Weight on \(\log(1 + t)\). Default: @0.25@.
  109   , cwViolation  :: !Double
  110     -- ^ Penalty per 'BlanketViolation' (subtracted). Default: @10.0@.
  111   }
  112   deriving stock (Eq, Show, Generic)
  113   deriving anyclass (NFData, FromJSON, ToJSON)
  114 
  115 -- | The reference weights used throughout the system unless an
  116 -- experiment overrides them via 'computeConatusEnergyWith' or
  117 -- 'computeConatusGradientWith'.
  118 defaultConatusWeights :: ConatusWeights
  119 defaultConatusWeights = ConatusWeights
  120   { cwMorphology = 1.0
  121   , cwIdentity   = 0.5
  122   , cwTurns      = 0.25
  123   , cwViolation  = 10.0
  124   }

  126 -- | The decomposed scalar contribution of each axis. Kept separate
  127 -- from 'ConatusEnergy' so that diagnostics and observability can
  128 -- show which axis is carrying (or failing) the system, not only the
  129 -- aggregate.
  130 data ConatusComponents = ConatusComponents
  131   { ccMorphology :: !Double
  132     -- ^ \(w_m \cdot \log(1 + m)\).
  133   , ccIdentity   :: !Double
  134     -- ^ \(w_c \cdot \log(1 + c)\).
  135   , ccTurns      :: !Double
  136     -- ^ \(w_t \cdot \log(1 + t)\).
  137   , ccPenalty    :: !Double
  138     -- ^ \(-\lambda \cdot |v|\). Always @<= 0@.
  139   }
  140   deriving stock (Eq, Show, Generic)
  141   deriving anyclass (NFData, FromJSON, ToJSON)

  143 -- | The scalar value of the Conatus functional together with its
  144 -- per-axis decomposition. Invariant: @ceScalar == sum of all four
  145 -- 'ConatusComponents' fields@.
  146 data ConatusEnergy = ConatusEnergy
  147   { ceScalar     :: !Double
  148     -- ^ \(C(b, v)\), the aggregate.
  149   , ceComponents :: !ConatusComponents
  150     -- ^ The per-axis breakdown.
  151   }
  152   deriving stock (Eq, Show, Generic)
  153   deriving anyclass (NFData, FromJSON, ToJSON)

  155 -- | The gradient of the smooth part of \(C\) at a blanket. Each
  156 -- component is the partial derivative of \(C\) with respect to that
  157 -- blanket axis, treating the blanket fields as real-valued for the
  158 -- duration of the derivative. The violation penalty contributes
  159 -- nothing because it is a step function in \(|v|\), not a smooth
  160 -- function of \((m, c, t)\).
  161 --
  162 -- All components are strictly positive on any blanket whose
  163 -- integer fields are non-negative (which is the universe of all
  164 -- legitimately-constructed 'SelfBlanket' values), so the gradient
  165 -- always points into the strictly-growing orthant.
  166 data ConatusGradient = ConatusGradient
  167   { cgMorphology :: !Double
  168     -- ^ \(w_m / (1 + m)\).
  169   , cgIdentity   :: !Double
  170     -- ^ \(w_c / (1 + c)\).
  171   , cgTurns      :: !Double
  172     -- ^ \(w_t / (1 + t)\).
  173   }
  174   deriving stock (Eq, Show, Generic)
  175   deriving anyclass (NFData, FromJSON, ToJSON)
  176 
  177 -- | Compute the Conatus energy of a blanket under the supplied
  178 -- violation list, using 'defaultConatusWeights'. Pure, total, and
  179 -- well-defined on every legitimately constructed blanket including
  180 -- the degenerate \((0, 0, 0)\) case.
  181 computeConatusEnergy :: SelfBlanket -> [BlanketViolation] -> ConatusEnergy
  182 computeConatusEnergy = computeConatusEnergyWith defaultConatusWeights
  183 
  184 -- | Compute the Conatus energy under explicit weights. Used by
  185 -- tests and experiments that perturb the coefficients; production
  186 -- code should call 'computeConatusEnergy'.
  187 computeConatusEnergyWith :: ConatusWeights -> SelfBlanket -> [BlanketViolation] -> ConatusEnergy
  188 computeConatusEnergyWith w b violations =
  189   let m         = fromIntegral (sbMorphologyTotalSize b) :: Double
  190       c         = fromIntegral (sbIdentityClaimsCount b) :: Double
  191       t         = fromIntegral (sbTurnCount           b) :: Double
  192       mComp     = cwMorphology w * log1p m
  193       cComp     = cwIdentity   w * log1p c
  194       tComp     = cwTurns      w * log1p t
  195       penalty   = negate (cwViolation w * fromIntegral (length violations))
  196       comps     = ConatusComponents
  197         { ccMorphology = mComp
  198         , ccIdentity   = cComp
  199         , ccTurns      = tComp
  200         , ccPenalty    = penalty
  201         }
  202    in ConatusEnergy
  203         { ceScalar     = mComp + cComp + tComp + penalty
  204         , ceComponents = comps
  205         }
  206 
  207 -- | Compute the gradient of the smooth part of Conatus at a blanket,
  208 -- using 'defaultConatusWeights'. Independent of the violation set.
  209 computeConatusGradient :: SelfBlanket -> ConatusGradient
  210 computeConatusGradient = computeConatusGradientWith defaultConatusWeights
  211 
  212 -- | Compute the gradient under explicit weights.
  213 computeConatusGradientWith :: ConatusWeights -> SelfBlanket -> ConatusGradient
  214 computeConatusGradientWith w b =
  215   let m = fromIntegral (sbMorphologyTotalSize b) :: Double
  216       c = fromIntegral (sbIdentityClaimsCount b) :: Double
  217       t = fromIntegral (sbTurnCount           b) :: Double
  218    in ConatusGradient
  219         { cgMorphology = cwMorphology w / (1 + m)
  220         , cgIdentity   = cwIdentity   w / (1 + c)
  221         , cgTurns      = cwTurns      w / (1 + t)
  222         }
  223 
  224 -- | Euclidean magnitude of a Conatus gradient. Useful as an
  225 -- /urgency/ scalar: a recovery system can compare magnitudes to
  226 -- decide whether the current state warrants intervention at all.
  227 gradientMagnitude :: ConatusGradient -> Double
  228 gradientMagnitude g =
  229   sqrt (cgMorphology g ^ (2 :: Int) + cgIdentity g ^ (2 :: Int) + cgTurns g ^ (2 :: Int))
  230 
  231 -- | Normalise a gradient to unit Euclidean magnitude. Returns
  232 -- @Nothing@ when the gradient is the zero vector (which can only
  233 -- happen if all weights are zero, since blanket fields contribute
  234 -- @1 / (1 + x) > 0@ for any finite \(x \geq 0\)).
  235 gradientNormalize :: ConatusGradient -> Maybe ConatusGradient
  236 gradientNormalize g =
  237   let mag = gradientMagnitude g
  238    in if mag == 0
  239         then Nothing
  240         else Just ConatusGradient
  241           { cgMorphology = cgMorphology g / mag
  242           , cgIdentity   = cgIdentity   g / mag
  243           , cgTurns      = cgTurns      g / mag
  244           }
  245 
  246 -- | The signed scalar drop in Conatus attributable to a list of
  247 -- violations under given weights. Exposed for diagnostics; the same
  248 -- value already appears as 'ccPenalty' in any 'ConatusEnergy'
  249 -- record computed under matching weights.
  250 conatusViolationPenalty :: ConatusWeights -> [BlanketViolation] -> Double
  251 conatusViolationPenalty w vs = negate (cwViolation w * fromIntegral (length vs))
  252 
  253 -- | Numerically robust \(\log(1 + x)\) for \(x \geq 0\). Avoids
  254 -- catastrophic cancellation for small \(x\), and is well-defined
  255 -- and equal to @0@ at \(x = 0\). The standard Haskell 'log'
  256 -- composed with @(+ 1)@ would also give the correct value on
  257 -- the inputs we feed it (non-negative integers cast to 'Double'),
  258 -- but expressing the operation explicitly documents the intent.
  259 log1p :: Double -> Double
  260 log1p x = log (1 + x)
