# Security Policy

## Supported branch

- `main`

## Reporting a vulnerability

Please report vulnerabilities privately before public disclosure.

Recommended report content:

1. Affected component and file path
2. Reproduction steps
3. Impact assessment
4. Proposed mitigation (optional)

Use GitHub Security Advisories for coordinated disclosure when available.

## Response targets

- Initial response: within 7 days
- Triage decision: within 14 days
- Patch timeline: depends on severity and reproducibility

## Scope notes

QxFx0 includes optional external integrations (Nix, Agda, GF runtime, HTTP
sidecar). Reports should clearly specify which integration is required for
reproduction.
