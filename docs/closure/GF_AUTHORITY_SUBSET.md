## 0. Why this document exists

The closure plan's Package 4 says: "if the system builds
commitments from dialogue but cannot reliably parse its own
authority surface, the semantic core will be deaf. We need a
*semantic round-trip authority subset* — a small, well-bounded
surface language that the system can parse back to itself with
high coverage, distinct from the full rendered surface."

This document specifies that subset. It is the boundary between
"the system can commit this and re-parse it" (authority-bearing)
and "the system can render this but cannot re-parse it"
(non-authority-bearing surface).

## 1. The problem in one sentence

The full rendered surface (every `Text` fragment in
`Render/Dialogue.hs`, every `Render.Surface.*` function, every
`QxFx0.Render.LocalRecovery.renderLocalRecoverySurfaceRu`
branch) is large, multilingual, and intentionally varied for
naturalness. The parser can re-parse some of it; the rest is
authored for the human reader.

If the system tries to commit the **full surface** as typed
semantic commitments, the parser will silently fail on a large
fraction of inputs. The semantic core (Package 2) will become
unreliable.

The fix is to identify the **subset** of the surface that is
authority-bearing — the fragments the system itself treats as
load-bearing — and parse only that.

## 2. Definition

A surface fragment is **authority-bearing** if all of the
following hold:

1. **It is a typed fragment.** The fragment is generated by a
   closed `Render.Surface.*` function whose output type is
   `AuthoritySurface Text` (a marker newtype), not `Text`.
2. **It is parser-complete.** For every value of the marker
   newtype, the parser returns a typed semantic observation
   (per Package 2's `FactualClaimPayload` shape) with 100%
   coverage.
3. **It is round-trippable.** For every typed observation that
   can be parsed from an authority-bearing surface, the
   corresponding authority-bearing surface can be re-rendered
   byte-for-byte. (This is the "high round-trip coverage" the
   closure plan requires.)
4. **It is traceable.** The fragment is associated with a
   `trcAuthoritySurface` field in `TurnReplayTrace`, with the
   fragment's id and the parser's typed observation.

A surface fragment that does not satisfy all four is
**non-authority-bearing**: it is rendered for the human, but
not committed, not parsed, and not part of the semantic
authority surface.

## 3. Initial authority subset (candidates)

The closure plan's Package 4 does not require a complete
inventory in this document. It requires **the discipline** and
**the first concrete subset** that proves the discipline works.

The first concrete subset is **commitment statements**:

### 3.1 What is in the subset

- A "commitment statement" is a short declarative sentence in
  the system's rendered output that asserts a fact about the
  world, the user, or the dialogue state.
- Examples (English):
  - "The user is a software developer."
  - "The current topic is the closure plan."
  - "The system has retracted its earlier claim about X."
  - "The system has committed to EssenceDialogical."
- Examples (Russian):
  - "Пользователь — разработчик."
  - "Текущая тема — план закрытия."
  - "Система отозвала своё более раннее утверждение о X."
  - "Система приняла EssenceDialogical."

These are the fragments that the **parser** must be able to
re-parse to a typed `FactualClaimPayload`. Anything outside
this category is non-authority-bearing.

### 3.2 What is NOT in the subset (initial pass)

The initial pass explicitly excludes:

- **Local recovery surface** (the entire
  `renderLocalRecoverySurfaceRu` / `renderLocalRecoverySurfaceEn`
  family). These are operator-facing fragments; they describe
  the system's recovery state, not facts about the world. The
  parser should not commit them.
- **Question surfaces** (e.g. "Что вы имеете в виду?"). The
  parser should not commit questions.
- **Acknowledgement phrases** (e.g. "Понял."). The parser
  should not commit acknowledgements.
- **Greeting and farewell surfaces.** Non-authority.
- **Localised recovery headers** ("Локальный режим
  восстановления."). Non-authority.
- **Diagnostic surfaces** (debugging-only `Render` functions).
  Non-authority by definition.
- **Multilingual variants** of the same commitment statement.
  These are author-generated variants; the parser should
  recognise the canonical English or Russian form, not every
  translation.

### 3.3 What gets committed in the initial pass

Only the **commitment statement** class. The closure plan's
Package 2 ships this; Package 4 is the discipline that limits
the parser to it.

## 4. The `AuthoritySurface` marker

```haskell
-- | Marker newtype: a Text fragment that is authority-bearing.
-- Render functions that produce authority-bearing output must
-- return AuthoritySurface; non-authority-bearing functions
-- return plain Text.
newtype AuthoritySurface = AuthoritySurface { unAuthoritySurface :: Text }
  deriving stock (Eq, Show)
  deriving newtype (IsString, ToJSON, FromJSON)

-- | Parse an authority surface back to a typed observation.
-- Total: returns Nothing for non-authority surfaces or for
-- surfaces that fail the parser.
parseAuthoritySurface :: AuthoritySurface -> Maybe FactualClaimPayload

-- | Render a typed observation as an authority surface.
-- Total: every FactualClaimPayload has a canonical rendering.
renderAuthoritySurface :: FactualClaimPayload -> AuthoritySurface
```

The round-trip property:
```haskell
roundTripProperty :: FactualClaimPayload -> Bool
roundTripProperty p =
  parseAuthoritySurface (renderAuthoritySurface p) == Just p
```

The closure plan's Package 4 ships a test suite
(`Test.Suite.AuthoritySurface`) that checks this property for
**every** `FactualClaimPayload` reachable by the test generators.

## 5. The boundary rule

A render function in `Render/*` that produces
authority-bearing output **must** return `AuthoritySurface Text`,
not `Text`. A render function that returns `Text` is by
definition non-authority-bearing and the parser will not commit
its output.

This is enforced by `scripts/check_architecture.sh` (extension
to ADR-0034 §3): a grep for `Text` in the return type of
`Render/*` functions that have "Authority" or "Commitment" in
their name is required to return `AuthoritySurface Text`.

## 6. Parser completeness (the round-trip coverage number)

The closure plan's Package 4 requires **high round-trip
coverage** for the authority subset. The initial pass targets
**100% coverage on the canonical commitment-statement subset**
in English and Russian. This is achievable because the subset
is small and the canonical forms are enumerable.

The number is measured by:

```haskell
coverageCorpus :: [FactualClaimPayload] -> [AuthoritySurface] -> Double
coverageCorpus payloads surfaces =
  let rendered = map renderAuthoritySurface payloads
      parsed = map parseAuthoritySurface surfaces
      matched = length [ p | (p, s) <- zip payloads surfaces
                          , parseAuthoritySurface s == Just p ]
  in fromIntegral matched / fromIntegral (length payloads)
```

Initial target: `coverageCorpus ≥ 0.99` on a corpus of
1 000 representative `FactualClaimPayload` × 2 languages.

## 7. The `sql_gf_canonicality_map.md` cross-reference

`docs/sql_gf_canonicality_map.md` (28 484 bytes) is the existing
map of SQL and GF canonical surfaces. The closure plan's
Package 4 reads this document and:

1. Identifies which GF rules are authority-bearing (the
   commitment-statement class).
2. Identifies which GF rules are non-authority-bearing (the
   rest).
3. Refactors the GF grammar so the authority-bearing rules
   have a clear, parser-complete surface, and the
   non-authority-bearing rules are tagged as such.

The refactor is a multi-day effort; Package 4 ships the
discipline and the first subset, not the complete refactor.

## 8. What Package 4 does **not** do

- It does not parse the **entire** rendered surface. That is
  impossible at the level of natural-language variety the
  project aims for.
- It does not require 100% coverage on **all** GF rules. Only
  on the authority subset.
- It does not change the **rendering** of non-authority
  surfaces. They remain authored for the human reader.
- It does not introduce a new parser. The existing parser
  (per `Semantic.Sense.Extract` and friends) is extended with
  the `parseAuthoritySurface` function, not replaced.
- It does not change the LLM transport. The LLM, if enabled,
  is **also** a parser; its outputs must pass through
  `parseAuthoritySurface` and only the parsed payloads are
  committed. LLM free-form answers are non-authority.

## 9. Acceptance criteria for Package 4 closure

- [ ] `QxFx0.Render.Authority` module (new) exposes the
      `AuthoritySurface` newtype, `parseAuthoritySurface`,
      `renderAuthoritySurface`, and the `roundTripProperty`.
- [ ] `QxFx0.Semantic.AuthorityParse` module (new) exposes
      `parseAuthoritySurface` over the existing
      `Semantic.Sense.Extract` pipeline.
- [ ] `Test.Suite.AuthoritySurface` (new) ships with:
      - `roundTripProperty` on the test generators;
      - `coverageCorpus ≥ 0.99` on the 1k × 2-language corpus;
      - a regression lock that the non-authority subset
        (local recovery, greetings, etc.) parses to `Nothing`.
- [ ] `scripts/check_architecture.sh` is extended with the
      boundary rule of §5.
- [ ] `docs/sql_gf_canonicality_map.md` is updated with the
      authority-bearing / non-authority-bearing split.
- [ ] At least **one** existing render function in
      `Render/Surface/*` is migrated to return
      `AuthoritySurface Text` as the model for future
      migrations.
- [ ] The closure plan's Package 2 (semantic commitments)
      calls `parseAuthoritySurface` before `commitObservation`;
      a `Nothing` parse is logged to trace, not committed.

## 10. Honest limits

- The initial subset is **commitment statements** in English
  and Russian. Adding more languages or more statement classes
  is a follow-up slice; the discipline is in place.
- The 100% round-trip property is for the **canonical
  rendering**, not for every translation. A user-facing
  translation that fails round-trip is **expected** to be
  non-authority-bearing; the canonical English or Russian form
  is what gets committed.
- The "high round-trip coverage" target is **99%** on the
  test corpus. 100% is aspirational; the closure plan
  recognises that corpus-level coverage is the right metric,
  not per-statement coverage.
- The discipline assumes the parser is honest. A
  bug-introducing parser that maps unrelated surfaces to
  typed observations is a security concern, not a coverage
  concern. The closure plan's Package 8 (bounded learning)
  includes a parser-trust discipline; Package 4 does not.
