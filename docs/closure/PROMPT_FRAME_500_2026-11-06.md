# 500-prompt sampling frame — measured composition (2026-11-06)

- **Status**: frame measured; **not** a labeled corpus, **not** a frozen
  packet. The 500-prompt gate remains **BLOCKED**.
- **Tool**: `scripts/eval/prompt_frame_500.py` (eval-only quarantine;
  `--self-test` 25/25).
- **Purpose**: turn the "no labeled 500-prompt corpus" blocker into a
  measurable sampling frame before anyone spends the ~17 h labeling budget.
  This document records what a uniform draw would actually contain; it does
  not choose between the two honest readings of the gate (see §4).

**The number that matters: 5 of 500 prompts are GF-mapped.** The pilot
protocol estimated "~3 GF / ~497 text path" from the 0.66% row coverage; the
measured frame gives 5 / 495. A uniform 500-prompt gate drawn today is a
**text-path** gate, not an M7/GF gate.

## 3. What this is not

- Not 500 labels. The tool generates prompts; it does not answer, score or
  adjudicate them.
- Not a frozen packet. No file is committed as the 500-prompt set; the frame
  is reproducible from the seed and the input hashes, and freezes only after
  the owner chooses §4 A or B.
- Not evidence of coverage or quality. It is a sampling measurement.
- Not a change to the 500-prompt gate status: **BLOCKED** until 500 labeled
  rows exist.

## 4. The decision this measurement informs

The pilot protocol names two honest readings:

| option | what it measures | cost | what it needs |
|---|---|---|---|
| **A — GF path at scale** | M7 pipeline | slot coverage + labeling | finish slot coverage (B, then C), then draw a GF-enriched frame |
| **B — text path at scale** | the unmapped text path | ~17 h labeling | explicitly rename the gate; do not call it M7 |

The measured 5/500 GF share is the reason A cannot be done by relabeling the
uniform frame: even after the `oov-005` fix, a uniform draw still measures the
text path. If the goal is M7, the slot batch (S2/S3) comes first; if the goal
is text-path quality, the gate must say so in its name and its report.

## 5. Reproduce

```bash
python3 scripts/eval/prompt_frame_500.py --self-test
python3 scripts/eval/prompt_frame_500.py --seed qxfx0-500-2026-11-06
# optional, for inspection only (not committed):
python3 scripts/eval/prompt_frame_500.py --seed qxfx0-500-2026-11-06 \
  --out /tmp/opencode/frame500.tsv --manifest /tmp/opencode/frame500.json
```

The manifest records the seed, the requested size, the population counts, the
frame composition and the SHA-256 of all five input files, so a later run can
prove it read the same corpus.
